# PLAS-45 纪元 + RS-422 电磁炮

本 release 提供 **三个互斥版本**，按需求只启用其中一个，**不要同时启用**。

## 版本选择

- **0.1.5**（`Epoch-Railgun-No-Overload-Explosion-0.1.5-experimental.zip`）
  移除纪元过载爆炸、纪元 4 发弹匣、电磁炮取消过充炸膛、装填时间减半，并额外把电磁炮默认瞄具换成 APW-1 反器材步枪的原生 10× 狙击镜。
  十倍镜需要你使用和我一样的瞄镜才有意义，无需求请选 0.1.3。

- **0.1.3**（`Epoch-Railgun-No-Overload-Explosion-0.1.3-experimental.zip`）
  同上，但**不含**十倍镜。正常的免炸膛版本。

- **0.1.0**（`Epoch-Railgun-Safe-Autofire-0.1.0-experimental.zip`）
  纪元单匣容量 3 → 4 发，并附带纪元与电磁炮的蓄力参数改动。
  **纪元过充后炸膛是此版本故意保留的设计**，用户实测会炸膛，与预期一致 —— 这不是 bug，也不是"更新失败"。此版不是免炸膛或安全满蓄力自动发射版。

## 共同改动（0.1.3 / 0.1.5）

- PLAS-45 纪元：将原版 3.25 秒过载事件阈值设为引擎定义的禁用值 0，并移除爆炸类型；可以继续保持蓄力
- RS-422 电磁炮：关闭过充炸膛标志，并移除过载爆炸类型；可以继续保持蓄力
- 纪元单匣容量：3 → 4 发
- 电磁炮弹药结构完全保留原版：单发装填、初始 10 个备用、补给 10 个、最多 20 个备用
- 两把武器的完整装填时间减半（装填速度翻倍）
- 不改动备用弹匣数、最大携带弹匣数、补给量、伤害或蓄力倍率

## 依赖

**只需要 Bingus Shared Loader v15 及以上**（或兼容的新版本）。

无需其他前置，下载即用。

## 安装

先彻底退出游戏。把选定的那一个版本 ZIP 导入 Arsenal / HD2 Mod Manager，**只启用一个版本**，启用后部署。Loader 放到列表最后（若开启「首个 mod 优先」则放最前）。

## 版本与适配

- 适配游戏构建 **25327279**。
- 0.1.5：运行时受保护写入与回读已通过，用户已实测确认生效。
- 0.1.3：已通过离线验证，**未单独做运行时实测**。
- 0.1.0：已通过离线验证；纪元过充炸膛行为已经用户实测确认（属预期设计）。

## 注意

- 内存模组属**客户端运行时改动**：只在本次游戏会话内生效，退出游戏即恢复原状。
- 联机表现可能与队友不一致，并存在**反作弊风险**。建议仅在知情固定队环境中使用。
- 卸载：用管理器禁用本包并重新部署；手动安装需保持 `patch_N` 编号连续，**不要直接删除中间编号的文件**。
